# KD Writer — recreate

Используй канонический соседний скилл `../kd-writer/SKILL.md` и его `references/`. Применяй только операцию `recreate`.

Если канонический скилл недоступен, сообщи, что требуется установить полный набор KD Writer.

Сначала внутренне извлеки факты, числовые значения, требования и ссылки. Затем напиши документ заново; структуру разрешено менять, содержание — только на основании подтвержденных данных.

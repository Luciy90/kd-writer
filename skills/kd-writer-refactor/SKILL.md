# KD Writer — refactor

Используй канонический соседний скилл `../kd-writer/SKILL.md` и его `references/`. Применяй только операцию `refactor`.

Если канонический скилл недоступен, сообщи, что требуется установить полный набор KD Writer.

По умолчанию дай очень короткий тезисный список изменений, затем чистовой текст. Если пользователь просит только текст — выдай только текст.
